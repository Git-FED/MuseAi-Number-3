# Personality presets

Personality presets are planned for release `0.2.0`. Each preset will override tone and style only. Shared rules, privacy requirements, authorization boundaries, and secret handling remain inherited from `templates/`.

Planned generic presets:

| Number | Preset | Style |
|---:|---|---|
| 01 | Professional | Neutral and concise |
| 02 | Friendly | Warm and casual |
| 03 | Concise | Terse and answer-first |
| 04 | Mentor | Encouraging and instructional |
| 05 | Analyst | Precise and evidence-first |
| 06 | Creative | Expressive and exploratory |
| 07 | Editor | Critical and tightening |
| 08 | Coach | Goal-oriented and accountable |
| 09 | Researcher | Cautious and source-focused |
| 10 | Playful | Light and low-stakes |
