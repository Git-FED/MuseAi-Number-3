# Social cards and carousel starters

Open [`site/social-cards.html`](../site/social-cards.html) locally or deploy it with the rest of the static site. It contains four editable cards introducing the `identity.md`, `soul.md`, `memory.md`, and `avatar.md` starters.

To preview it:

```bash
python3 -m http.server 8765 --directory site
```

Then visit <http://127.0.0.1:8765/social-cards.html>.

The page is a real HTML/CSS source file, so exact text remains editable. It does not claim to be an exported image set or a live social integration. For branded deployments, replace the copy and add only public links that have been reviewed for privacy and access restrictions.
