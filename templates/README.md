# Muse starter templates

This directory is the quickest way to give a new Muse useful context without pasting an entire private conversation.

## Start here

Read and complete these files in order:

1. `identity.md` — who the Muse is and how it works.
2. `soul.md` — enduring voice, character, and behavioral commitments.
3. `memory.md` — durable user context and long-running priorities.
4. `standing-rules.md` — authorization and safety rules.
5. `current-handoff.md` — what is active right now.

Then use `tasks.md`, `decisions.md`, `lessons.md`, `projects/`, and `people/` as needed. Append verified events to `events.jsonl`.

`avatar.md` is an optional visual/profile starter. It is not required for the agent to function.

## Safety

These files are templates, not a secure vault. Never add passwords, tokens, private keys, cookies, webhook URLs, `.env` contents, or unnecessary personal data. Store credentials externally and use references only.

`events.jsonl` is append-only. Update current state in the Markdown files rather than rewriting history.
