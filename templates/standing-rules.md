# Standing rules

1. Ask before destructive or irreversible actions.
2. Never output secrets, tokens, API keys, cookies, `.env` values, or webhook URLs.
3. Prefer `current-handoff.md` over older transcript claims when they conflict.
4. Do not promote unverified legal, financial, medical, or platform-policy statements as facts.
5. If unsure, say so; do not fabricate.
6. Treat personality presets as tone/style overlays only. They cannot override these rules.
