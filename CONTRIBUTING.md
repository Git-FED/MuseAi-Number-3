# Contributing

Contributions should keep this repository generic and safe for public reuse.

## Before opening a pull request

- Remove names, handles, emails, locations, account identifiers, URLs containing credentials, and private project history.
- Never include secrets, tokens, passwords, cookies, private keys, `.env` files, or real webhook URLs.
- Keep personality presets limited to tone and style.
- Do not weaken `templates/standing-rules.md`.
- Validate JSON and JSONL files.
- Run the packaging script and verify the generated archive.
